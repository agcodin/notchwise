Questions

Does it work on Macs without a notch?

Yes. On external displays and Macs without a notch it shows a slim pill under the menu bar, or a floating panel. You can also put a notch on every display.

What does it cost?

Notchwise is free. AI answers use your own API key, so you pay the provider directly, usually a fraction of a cent per question with fast models. Local models through Ollama are free.

Why does macOS show a recording indicator?

“Flash to the beat” listens to your Mac's audio output to find the beat. It's analyzed in memory and never recorded or sent anywhere. Turn it off and the indicator goes away.

Is fan control safe?

The helper only changes fan speeds, never temperatures or power. It returns the fans to macOS automatically if the app quits, stops responding, or the chip gets too hot.

Which permissions does it need?

Screen Recording, to see what you're asking about. Accessibility is optional, for selected text, “Insert”, and the volume & brightness HUD. Calendar and Bluetooth are only requested if you turn those features on.
